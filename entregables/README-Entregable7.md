# Entregable 7 · Documentación y Presentación

**Complejidad:** Media. Documenta todo el proyecto para que otros lo usen y mantengan.

## Los 8 componentes

| # | Componente | Archivo | Formato |
|---|-----------|---------|---------|
| 1 | Documentación técnica | `Entregable7-Documentacion.docx` (sección 1) | Word |
| 2 | Guía de usuario | `Entregable7-Documentacion.docx` (sección 2) | Word |
| 3 | Diccionario de datos | `Entregable7-Documentacion.docx` (sección 3) | Word |
| 4 | Limitaciones | `Entregable7-Documentacion.docx` (sección 4) | Word |
| 5 | Roadmap | `Entregable7-Documentacion.docx` (sección 5) | Word |
| 6 | Presentación ejecutiva | `Entregable7-Presentacion-Ejecutiva.pptx` | PowerPoint (13 slides) |
| 7 | Video tutorial (5 min) | `Entregable7-Guion-Video-Tutorial.md` | Guion listo para grabar |
| 8 | README de setup | `../README.md` | Markdown |

## Notas de formato

- **Documentación (1–5):** reunidas en un único `.docx` con portada, secciones y tablas, para
  facilitar su lectura e impresión como documento de 4–6 páginas.
- **Presentación (6):** `.pptx` nativo de 13 slides (dentro del rango 10–15) con la paleta UAO,
  editable en PowerPoint, LibreOffice Impress o Google Slides.
- **Video (7):** el entorno no permite grabar video, por lo que se entrega un **guion profesional
  de 5 minutos** con tiempos, narración y acciones en pantalla, más una checklist de producción.
  Está listo para grabarse con OBS/Loom siguiendo el recorrido indicado.
- **README (8):** el `README.md` de la raíz del repositorio, reescrito como guía maestra del
  proyecto con instrucciones de setup y la estructura completa.
