# Imágenes institucionales del dashboard

El dashboard (`dashboard-bajas-uao.html`) busca estas dos imágenes en esta carpeta:

| Archivo | Qué es | Dónde se muestra |
|---|---|---|
| `logo-uao.png` | Logo oficial UAO (rojo, con nombre completo) | Encabezado, junto al título |
| `pie-uao.png` | Pie institucional (dirección, PBX, personería jurídica) | Parte inferior de la página |

Si un archivo no existe, el dashboard muestra automáticamente el diseño anterior (cuadro rojo "UAO" y pie de texto),
por lo que nunca queda un ícono de imagen rota.

## Cómo agregarlas
1. Guarda el logo como `logo-uao.png` y el pie como `pie-uao.png` (nombres exactos, en minúsculas).
2. Cópialas en esta carpeta (`assets/`) junto a `indice-entregables.svg`.
3. Recarga el dashboard (Ctrl+F5).

Recomendado: logo con fondo transparente y unos 400 px de alto; pie de unos 1000 px de ancho.
